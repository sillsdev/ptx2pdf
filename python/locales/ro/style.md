Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Romanian is there to help them read the screen faster, not to be a literary translation.

- Register: polite, formal plural. Instructions use the "dumneavoastră" imperative forms: Selectați, Faceți clic, Introduceți, Utilizați, Alegeți. Never use the informal singular (alege, folosește, ești sigur). Rewrite any informal sentence to the formal form ("Dacă nu sunteți sigur ...").
- Orthography: always use the correct comma-below letters ș, ț (never the cedilla forms ş, ţ) together with ă, â, î. Use the standard spelling of the current Romanian Academy norms (î at the start/end of words, â inside).
- Labels and buttons: a short noun phrase or the imperative. Tooltips and messages: complete natural sentences. Never translate word by word; translate the meaning (see the term notes). If a literal rendering reads as nonsense or is a different word, rethink it.
- Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w. Keep PDF and similar acronyms.
- Bible terms use the standard Romanian vocabulary: capitol (chapter), verset (verse), carte (book), Biblia (Bible), Scriptura (Scripture).
- Common computing words use the usual Romanian terms or the common loanword: fișier (file), dosar (folder), filă (tab), font, margine (margin), imagine (picture), setări (settings).
- Every translation must keep each placeholder ({}, %s, %(name)s), tag and blank-line paragraph break exactly as in the English.
