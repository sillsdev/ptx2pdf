Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Indonesian is there to help them read the screen faster, not to be a formal translation.

- Register: polite standard Indonesian. Address the user as "Anda" (never "kamu", "lu", or "-mu"). Do not add "silakan" to every instruction; use it only when it reads more natural, e.g. in a longer message.
- Buttons and menu items: the bare verb root (Pilih, Buka, Simpan, Hapus, Cetak). Labels: a short noun phrase. Tooltips and messages: full, plain sentences. Prefer active "Anda dapat ..." or a plain imperative to heavy "di-" passives when clear.
- Capitalisation: follow the English: Title Case labels stay Title Case, sentences are sentences.
- Keep established computing loanwords as the existing translations do (file, font, folder, tab, email, PDF, pop-up). Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w.
- Bible terms use the standard Indonesian Alkitab vocabulary: pasal (chapter), ayat (verse), kitab (book), Alkitab (Bible), Kitab Suci (Scripture).
- Translate the meaning, not word by word. Avoid false friends and stiff calques (e.g. "credit" for a picture is the source attribution, not a financial credit).
- Keep sentences short; split long English sentences into two where it reads better.
- Punctuation: no space before a colon ("Nama file:").
