Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Arabic is there to help them read the screen faster, not to be a literary translation.

- Language: clear Modern Standard Arabic, no dialect. Short, direct wording. No tashkeel (vowel marks) except where needed to avoid ambiguity.
- Register: instructions use the masculine singular imperative, as is usual in Arabic software (اختر، انقر، أدخل، احفظ). Do not address the user with a pronoun.
- Labels and buttons: a short noun phrase or imperative verb. Tooltips and messages: complete, natural sentences. Never translate word by word; translate the meaning (see the term notes). If a literal rendering reads as nonsense, rethink it.
- Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w. Keep PDF and similar acronyms in Latin script. Leave these Latin items exactly as written inside the Arabic sentence.
- Use Western digits (0-9), as in the English. Use Arabic punctuation for sentence text (، ؟ ؛) but keep ":" for labels ending in a colon.
- Bible terms use standard Arabic Bible vocabulary: سفر (book), إصحاح (chapter), آية (verse), الكتاب المقدس (Bible).
- Common computing words use the usual Arabic terms (ملف file، مجلد folder، خط font، هامش margin، علامة تبويب tab) rather than transliteration.
- Every translation must keep each placeholder ({}, %s, %(name)s), tag and blank-line paragraph break exactly as in the English.
