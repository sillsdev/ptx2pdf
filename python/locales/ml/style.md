Audience: Bible translators and typesetters in Kerala and beyond who already know common English computing words (font, margin, PDF, file). The Malayalam is there to help them read the screen faster, not to be a literary translation.

- Language: simple, modern, everyday Malayalam as used in Malayalam software and newspapers. Avoid heavily Sanskritised or archaic words when a common word exists.
- Keep English computing words that Malayalam users actually say, written in Malayalam script: ഫോണ്ട് (font), മാർജിൻ (margin), ഫയൽ (file), ഫോൾഡർ (folder), ടാബ് (tab), ബട്ടൺ (button). Use a Malayalam word only where it is the normal one (ക്രമീകരണങ്ങൾ for settings, തിരഞ്ഞെടുക്കുക for select).
- Register: polite. Instructions use the polite -ുക form (തിരഞ്ഞെടുക്കുക, നൽകുക, ക്ലിക്ക് ചെയ്യുക). Do not use നീ.
- Labels and buttons: short noun phrases. Tooltips and messages: complete, natural sentences. Translate the meaning, never word by word (see the term notes); if a literal rendering reads as nonsense, rethink it.
- Spelling: Unicode with atomic chillu letters (ൽ ൻ ർ ൾ ൺ), not ZWJ sequences.
- Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w. Keep PDF and similar acronyms in Latin script. Strong's stays a name (സ്ട്രോങ്ങിന്റെ നമ്പറുകൾ, or keep "Strong's").
- Bible terms use the standard Malayalam Bible vocabulary: ബൈബിൾ, പുസ്തകം (book), അദ്ധ്യായം (chapter), വാക്യം (verse), അടിക്കുറിപ്പ് (footnote), ക്രോസ് റഫറൻസ് (cross-reference).
- Typesetting terms: ബോർഡർ (border), ഹെഡർ / ഫൂട്ടർ (header/footer), കോളം (column), പുസ്തകത്തിന്റെ നട്ടെല്ല് / സ്പൈൻ (spine; prefer സ്പൈൻ), ഒറ്റ / ഇരട്ട പേജുകൾ (odd/even pages).
- Strings containing markup such as <span ...> or <b>: translate only the visible words; leave the tags and attributes exactly as they are.
- Every translation must keep each placeholder ({}, %s, %(name)s), tag and blank-line paragraph break exactly as in the English. Never merge two paragraphs into one.
