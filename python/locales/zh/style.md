Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Chinese is there to help them read the screen faster, not to be a literary translation.

- Language: Simplified Chinese (zh-Hans, mainland usage). Use mainland computing terms (文件, 文件夹, 字体, 选项卡, 设置), not Taiwan/Hong Kong ones.
- Register: neutral and concise. Do not use pronouns (no 您/你); write instructions as bare verb phrases: 选择…, 单击…, 输入…, 保存…. Use 单击 for "click".
- Labels and buttons: short noun or verb phrases. Tooltips and messages: complete, natural sentences. Never translate word by word; translate the meaning (see the term notes). If a literal rendering reads as nonsense or a different thing (e.g. "tolerance" as "colour tolerance", "step" as "procedure"), rethink it.
- Punctuation: use full-width Chinese punctuation (，。：；？（））) in Chinese sentences. For labels ending in a colon use "：". Keep half-width punctuation inside placeholders, code and Latin text. Put no spaces between Chinese characters and adjoining Latin letters or numbers.
- Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w. Keep PDF and similar acronyms in Latin script.
- Bible terms use the standard Chinese Bible vocabulary: 卷 (book), 章 (chapter), 节 (verse), 圣经 (Bible), 经文 (Scripture).
- Typesetting terms: 边框 (border), 页边距 (margin), 脚注 (footnote), 交叉引用 (cross-reference), 侧边栏 (sidebar), 书脊 (spine), 出血 (bleed), 下划线 (underline).
- Strings containing markup such as <span ...> or <b>: translate only the visible words; leave the tags and attributes exactly as they are.
- Every translation must keep each placeholder ({}, %s, %(name)s), tag and blank-line paragraph break exactly as in the English.
