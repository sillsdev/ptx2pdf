Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Hungarian is there to help them read the screen faster, not to be a literary translation.

- Register: polite and formal. Address the user with the formal "Ön" forms in instructions and tooltips (Válasszon, Kattintson, Adja meg, Küldje el). Never use the informal "te" forms (Válassz, Kattints).
- Menu items, buttons and dialog titles: use the verbal noun as the existing translation does (a fájl kiválasztása, mentés, megnyitás), or a short noun phrase. Tooltips and messages: full sentences in the formal imperative or indicative.
- Capitalisation: Hungarian uses sentence case. Do not copy the English Title Case of labels (English "Page Border Color" -> "Oldalszegély színe").
- Translate the meaning, not word by word. Avoid false friends and literal calques (e.g. "credit" in a picture-credit/attribution sense is a source credit, not a financial credit; "thumb tab" is a tab cut into the page edge, not a thumb).
- Keep established technical loanwords as the existing translations do (fájl, szkript, PDF, e-mail, marker -> jelölő). Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w.
- Bible terms use the standard Hungarian vocabulary: fejezet (chapter), vers (verse), könyv (book), Szentírás (Scripture).
- Punctuation: no space before a colon or question mark ("Fájlnév:"). Keep an English trailing "..." as an ellipsis.
- Where English uses a placeholder, move it to where Hungarian grammar needs it, but keep it intact; remember that Hungarian suffixes attach directly to the following word, so prefer wording that does not need a suffix after a placeholder.
