Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Russian is there to help them read the screen faster, not to be a literary translation.

- Language: standard modern Russian, with the computing terms Russian software normally uses (файл, папка, шрифт, настройки, вкладка, предварительный просмотр).
- Register: address the user as «вы» (lower case). Buttons and menu commands use the infinitive (Сохранить, Отмена, Применить, Обзор…). Instructions in tooltips and messages use the polite imperative (Выберите…, Введите…, Нажмите…).
- Labels: short noun phrases. Tooltips and messages: complete, natural sentences. Translate the meaning, never word by word (see the term notes); if a literal rendering reads as nonsense, rethink it. Past-tense reports stay past tense (e.g. "Removed the file" = «Файл удалён»).
- Typography: use «ёлочки» quotation marks in Russian text; keep straight quotes inside placeholders and code. Use ё where it changes meaning (удалён, всё).
- Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w. Keep PDF and similar acronyms in Latin script. Strong's stays a name: номера Стронга.
- Bible terms use the standard Russian Bible vocabulary: Библия, книга, глава, стих (verse), сноска (footnote), параллельные места (Bible cross-references).
- Typesetting terms: рамка (border), поле (margin), колонтитул: верхний/нижний (header/footer), колонка (column), корешок (spine), вылет под обрез (bleed), корешковое поле (gutter), нечётные/чётные страницы (odd/even pages), предтекстовая часть (front matter), послетекстовая часть (back matter).
- Strings containing markup such as <span ...> or <b>: translate only the visible words; leave the tags and attributes exactly as they are.
- Every translation must keep each placeholder ({}, %s, %(name)s), tag and blank-line paragraph break exactly as in the English.
