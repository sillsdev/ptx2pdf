Audience: Bible translators and typesetters in Papua New Guinea who use PTXprint. Many know some English computing words. The Tok Pisin is there to help them read the screen faster.

- Language: standard Tok Pisin (as in Buk Baibel and Wantok). Short, simple sentences. Keep the sense of the English; never invent a descriptive phrase that changes the meaning.
- Technical terms with no established Tok Pisin word: keep the English word (font, margin, PDF, seting, boton, folder, tab). Do NOT invent a picturesque phrase for them; earlier drafts that did so produced nonsense (for example "Uniform Border Padding" became "must put a plank on the fence").
- Commands use the transitive "-im" imperative: Opim (open), Pasim (close), Seivim (save), Rausim (remove/delete), Kopiim (copy), Senisim (change), Makim (choose/select), Painim (find), Kamapim (create), Printim (print), Klikim (click). Say "Klikim dispela boton ..." for "Click this button ...".
- Useful function words: bilong (of), long (in/at/to), na (and), o (or), ol (plural marker), dispela (this), olgeta (all), wanpela (one/a), i ken (can), i no (not), sapos (if).
- Labels and buttons: very short. Tooltips: one or two short sentences. If something cannot be said clearly in Tok Pisin, give the shortest clear wording and keep the English technical word.
- Do not translate product and technical names: Paratext, PTXprint, USFM, FRT, XeTeX, ptx2pdf, and any code such as \k or \w.
- Bible terms: buk (book), kapitel (chapter), ves (verse), Baibel (Bible), Skripsa (Scripture).
- Every translation must keep each placeholder ({}, %s, %(name)s), tag and blank-line paragraph break exactly as in the English.
- This is a first draft from a model, not a native speaker: when unsure, prefer the simpler, more literal-but-clear wording and keep English technical words.
