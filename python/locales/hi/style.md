Audience: Bible translators and typesetters who already know common English computing words (font, margin, PDF, file). The Hindi is there to help them read the screen faster, not to be a formal translation.

- Use simple, everyday Hindi, understandable by a 10-11 year old. Avoid Sanskritised words (e.g. use जानकारी, not विवरण/ब्योरा; इस्तेमाल, not उपयोग; चालू करें, not सक्षम करें; सवाल, not प्रश्न; ब्रैकेट, not कोष्ठक; नाप, not आयाम).
- Address the user politely with "आप" forms (क्लिक करें, चुनें, जाएँ). Never use "तुम" or "तू". Prefer a short imperative for instructions.
- When there is no common Hindi word, keep the English word written in Devanagari (फ़ॉन्ट, मार्जिन, बॉर्डर, साइडबार, फ़्रंट मैटर). Do not coin new Hindi words for technical terms.
- Keep product and technical names in Latin script: Paratext, PTXprint, USFM, FRT, XeTeX, PDF, and any code such as \k or \w.
- Bible terms use the standard Hindi Bible vocabulary: अध्याय (chapter), पद (verse), किताब (book).
- Keep sentences short; split long English sentences into two Hindi sentences where it reads better.
- Use the danda "।" to end full Hindi sentences; keep ":" for labels that end in a colon in English.
- Use "ऑ" / "ज़" / "फ़" nukta forms normally (फ़ाइल, ज़ूम).
