# Glossary of terms

## How to use this glossary

This glossary explains the technical words and the PTXprint words used in this manual. The terms
are in alphabetical order. Where it helps, the definition says which chapter tells you more.

## 1–9

**1-up, 2-up, 4-up, 8-up** — How many book pages are printed on one side of a sheet of paper.
**1-up** is a normal PDF, one page on each PDF page. **2-up** puts two pages side by side, for a
folded booklet. Set this in **Pages Per Spread** (see the **Finishing tab** chapter).

## A

**Adj List (AdjList, adjustment list)** — The list of paragraph adjustments for each book. Each
row asks PTXprint to set one paragraph one line shorter or longer, or with slightly narrower or
wider letters. You make adjustments in the PDF Preview window, and you can see and edit the list
on the **View+Edit** tab, **Adj List** sub-tab.

**Adjustment (shrink, expand)** — A small change to one paragraph so that it uses one line less
(shrink) or one line more (expand), or so that its letters are a little narrower or wider. It is
used to make pages fill well. See the **PDF Preview** chapter.

**Align Text to Baseline** — A layout choice where every line sits on a fixed grid, so the lines on
the front and back of a sheet line up. The other choice is **Variable Line Spacing**. See the
**Layout tab** chapter.

**Alpha** — How solid a background colour is: 0 is clear (see-through), 1 is fully solid. Used for
the background of sidebars on the **Styles** tab.

**Anchor (Anchor Ref)** — The place in the text that a picture belongs to, usually a verse, for
example `MRK 4.39`. PTXprint tries to put the picture on the same page as its anchor. See the
**Pictures tab** chapter.

**Archive (ZIP archive)** — A ZIP file that holds everything needed to make your PDF again on
another computer: settings, text, fonts and pictures. Make it with **Create Archive...** on the
**Help** tab, and send it to the support team when you ask for help.

**Auto Page Fill (page filler)** — A tool in the PDF Preview window that tries to make every page
full, by adjusting paragraphs automatically. It can take a long time. See the **PDF Preview**
chapter.

**Auto-update** — An option in the PDF Preview window. When it is ticked, PTXprint makes a new PDF
by itself a few seconds after you adjust something in the preview.

## B

**Back matter** — The pages after the Scripture text, for example a glossary, maps, an index or a
colophon. See the **Peripherals tab** chapter.

**Base Font Size** — The size of the letters in normal paragraphs, in points. The size of all
other text (headings, notes, verse numbers) is set relative to it. Set it on the **Layout** tab.

**Base Indent** — The normal width of a paragraph indent. Other indents on the **Styles** tab are
given as a multiple of it. Set it on the **Layout** tab.

**Base Line Spacing** — The normal distance from one line of text to the next, in points. Set it on
the **Layout** tab.

**Baseline** — The invisible line that the letters sit on.

**Bible Module** — A Paratext file that lists passages to print together, for example for a
lectionary. You can print one from the **Basic** tab.

**Binding gutter** — Extra empty space at the inner edge of each page, near the spine, so that the
text does not disappear into the binding. See the **Layout tab** chapter.

**Bleed** — A picture or colour that goes past the edge of the page, so that no white strip shows
if the printer does not cut exactly. Usually about 3 mm. See the **Finishing tab** chapter.

**Book code** — The 3-letter code for a book in Paratext and USFM, for example `GEN`, `MAT`,
`JHN` or `1CO`. Use these codes when you type book lists in PTXprint.

**Book View** — A way to see two facing pages side by side in the PDF Preview window, as in a
printed book.

**BSB (Berean Standard Bible)** — A free English Bible that PTXprint can install for you, for
practice or as a second text in a diglot. See the **Basic tab** chapter.

## C

**Caller** — The small mark in the text (for example *a*, *b* or †) that tells the reader there is
a note. The same mark is often repeated at the start of the note. See the **Notes+Refs tab**
chapter.

**Caption** — The text printed with a picture, usually below it. See the **Pictures tab** chapter.

**Category** — A label that groups study notes or sidebars, for example "people" or "places".
All sidebars with the same category share one style.

**Changes file (changes.txt)** — A list of search-and-replace rules that PTXprint applies to a
temporary copy of the text before typesetting. The Paratext text is not changed. This is an
advanced feature on the **Advanced** tab.

**Chapter label** — A word printed before each chapter number instead of a large number alone,
for example "Psalm 1". Set it on the **Body** tab.

**Character style (character marker)** — A style for a few words inside a paragraph, for example
`\nd` (name of God) or `\w` (glossary word). Compare **paragraph style**.

**CMYK** — The four inks used by most colour printing presses: Cyan, Magenta, Yellow and blacK.
Many printers ask for a CMYK PDF. Choose it in **PDF Output Format** on the **Finishing** tab.

**Colophon** — A short text at the end of the publication with details about it, for example the
copyright, the printer and the picture credits. Turn it on and edit it on the **Peripherals** tab.

**Column Cross-References** — Cross-references printed in a narrow column of their own beside the
text, as in many reference Bibles. See the **Notes+Refs tab** chapter.

**Column gutter** — The empty space between two columns of text. See **gutter**.

**Configuration (config, layout)** — A named set of PTXprint settings for one project: page size,
fonts, pictures, styles, front matter and so on. One project can have many configurations, for
example a draft and a final one. You choose and make configurations on the **Basic** tab.

**Copyright statement** — The text that says who owns the rights to the text. PTXprint takes it
from Paratext, and you can change it on the **Basic** tab. It can be printed in the front matter
with `\zcopyright`.

**Cover** — The outside of the book: front cover, spine and back cover. PTXprint can make cover
pages. See the **Peripherals tab** chapter.

**Credit overlay** — A small copyright line printed on top of a picture. Some artists require it.
See the **Pictures tab** chapter.

**Crop marks (trim marks)** — Thin lines outside the corners of each page that show the printer
where to cut. Only add them if the printer asks for them. See the **Finishing tab** chapter.

**Cross-reference** — A note that lists other places in the Bible about the same thing, for
example "Gen 1:1; Ps 33:6". In USFM it is marked with `\x`. PTXprint can also add
cross-references from an external list. See the **Notes+Refs tab** chapter.

**Cutout** — A space cut into the side of a paragraph, so that the text flows around a small
picture or box. See the **Pictures tab** chapter.

## D

**DBL (Digital Bible Library)** — An online library of Scripture texts. You can download a text
bundle from it and install it in PTXprint (see the **Basic tab** chapter).

**Default configuration** — The configuration called **Default** that every project has. You
cannot delete it or lock it, but you can reset it.

**Diff PDF** — A PDF that shows in colour what changed between a new PDF and an older one. Make it
with **Compare PDFs** on the **Finishing** tab.

**Digit mapping** — An option that prints numbers with the digits of another script (for example
Arabic-Indic or Devanagari digits) when the text uses 0–9. Set it in the **Pick a Font** dialog
(see the **Fonts+Script tab** chapter).

**Diglot** — A publication with two texts side by side on the page, for example two languages.
Each text comes from its own Paratext project. See the **Diglot tab** chapter.

**Drop chapter number** — A large chapter number at the start of a chapter, two or more lines high,
with the text beside it.

**Dynamic border** — A border that PTXprint draws around text, a heading or a title, and that grows
with its contents. Compare **PDF border**. See the **Tabs+Borders tab** chapter.

## E

**em** — A unit of width equal to the size of the text. In 10 pt text, 1 em is 10 pt.

**End of Ayah** — A special character (U+06DD) used in Arabic script to decorate verse numbers.
See the **Tabs+Borders tab** chapter.

**Extended note (study note)** — A longer note, as in a study Bible. In USFM it is marked with
`\ef`. PTXprint prints extended notes in their own area at the bottom of the page. See the
**Notes+Refs tab** chapter.

**External cross-reference list** — A ready-made list of cross-references that comes with
PTXprint (or your own list). PTXprint can add these references to the publication. See the
**Notes+Refs tab** chapter.

## F

**Fake (faux) bold and italic** — Bold or italic letters that PTXprint makes from the regular
letters (thicker or slanted), when a font has no real bold or italic typeface.

**Fallback font** — A second font that PTXprint uses only for characters that the main font does
not have. It stops these characters printing as empty boxes. See the **Fonts+Script tab** chapter.

**Final SFM** — The text of a book after PTXprint has made all its changes, exactly as it was sent
to the typesetter. You can look at it (but not edit it) on the **View+Edit** tab.

**Font** — A set of letter shapes, for example *Charis SIL* or *Gentium Plus*. A font family
usually has four typefaces: Regular, Bold, Italic and Bold Italic.

**Font feature** — An option built into a font, for example a different shape for one letter, or
different digits. Choose features with **Select Features...** in the **Pick a Font** dialog.

**Footer** — The line at the bottom of each page, outside the main text. It can hold a page
number, a date or a short text. See the **Header+Footer tab** chapter.

**Footnote** — A note that explains something about the text. In USFM it is marked with `\f`. It
is usually printed at the bottom of the page. See the **Notes+Refs tab** chapter.

**Frame size** — The width of the area for a picture or box: one column, the full width (span),
a page inside the margins, or the whole sheet. See the **Pictures tab** chapter.

**Front matter** — The pages before the Scripture text, for example the title page, the copyright
page, the table of contents and a preface. In Paratext it is the FRT book. You make and edit it on
the **Peripherals** and **View+Edit** tabs.

**FRT** — The book code for front matter. PTXprint does not list it with the other books. Set up
the front matter on the **Peripherals** tab instead.

## G

**Glossary** — A list of words with their meanings, usually at the end of the publication. Its
book code is GLO.

**Glossary word** — A word in the text that has an entry in the glossary. In USFM it is marked with
`\w ...\w*`. Choose how glossary words look on the **Body** tab.

**Glyph** — The shape that a font draws for a character.

**Glyph collision** — Letters or marks that touch or overlap, for example a high mark that hits the
line above. **Layout Analysis** in the PDF Preview window marks these in red.

**Graph Paper** — A measuring grid that PTXprint can draw over the pages in the PDF Preview
window. It is not printed in the PDF.

**Graphite** — A "smart font" technology from SIL. Some fonts for complex scripts need it. Tick
**Graphite Rendering** in the **Pick a Font** dialog only for fonts that are made for Graphite.

**Grayscale (B/W)** — Only black ink, in shades of grey. Choose **Print-Gray (B/W)** on the
**Finishing** tab for a book printed only in black.

**Gutter** — An empty space. The *column gutter* is the space between two columns. The *binding
gutter* is extra space at the spine of the book. See the **Layout tab** chapter.

## H

**Hanging indent** — A paragraph where the first line starts further left than the other lines.
Poetry and lists often use it. Make it with a negative **First Line Indent Factor** on the
**Styles** tab.

**Header (running header)** — The line at the top of each page, outside the main text. It often
shows the book name, the chapter and verse references, and the page number. See the
**Header+Footer tab** chapter.

**Hyphenation** — Breaking a long word at the end of a line, usually with a hyphen (-), and
continuing it on the next line. PTXprint uses the hyphenation list from Paratext. See the
**Fonts+Script tab** chapter.

## I

**Image set** — A downloadable collection of Bible illustrations. You can search it in the picture
catalogue (**Show Catalogue...** on the **Pictures** tab).

**Imposition** — Arranging several book pages on one large sheet of paper, so that after folding
and cutting the pages come out in the right order. See **Booklet Pagination** in the **Finishing
tab** chapter.

**Interlinear** — Printing a gloss (a short translation) under or above each word of the text,
from the Paratext Interlinearizer. See the **Advanced tab** chapter.

**Introduction (book introduction)** — The text before chapter 1 of a book, with markers such as
`\is` and `\ip`. Choose whether to print it on the **Body** tab.

## J

**Justification (justified text)** — Text where both the left and the right edges of the lines are
straight. PTXprint stretches or shrinks the spaces between words to do this. Compare **ragged**.
Set it on the **Body** tab and the **Styles** tab.

## K

**Kashida (tatweel)** — A joining stroke (ـ) in Arabic script that makes a word longer. It can be
used to make lines look better. See the **Fonts+Script tab** chapter.

## L

**Layout Analysis** — A check in the PDF Preview window that looks for layout problems (wide
spaces, rivers, collisions and missing characters) and marks them in colour on the page.

**Layout Only** — A check box in the bottom bar. When it is ticked, PTXprint does not process the
text again if only layout settings changed, so printing is faster.

**Leading** — Another word for line spacing: the distance from the baseline of one line to the
baseline of the next. PTXprint calls it **Line Spacing**.

**Line spacing** — See **leading** and **Base Line Spacing**.

**Lines Per Page** — The number of lines of text that fit on a page, shown on the **Layout** tab.
It is blue when a whole number of lines fits, and red when there is wasted space.

**Lock Ratio** — A check box on the **Layout** tab that keeps the font size and the line spacing in
the same proportion. When you change one, PTXprint changes the other.

**Locked configuration** — A configuration that is protected with a password, so that nobody changes
or deletes it by mistake. See the **Basic tab** chapter.

## M

**Margin** — The empty space between the text and the edge of the page. Set the margins on the
**Layout** tab.

**Margin notes** — Footnotes, cross-references or headings printed in an extra column at the side
of the text, beside the verse they belong to. See the **Layout tab** and **Notes+Refs tab**
chapters.

**Marginal verses** — Verse numbers printed in a narrow column beside the text instead of inside
it. Set them on the **Body** tab.

**Marker (USFM marker)** — A short code that starts with a backslash and says what a piece of text
is. For example, `\p` starts a paragraph, `\s1` is a section heading, `\v` is a verse number and
`\f` is a footnote. Each marker has a style on the **Styles** tab.

**Merging mode** — How PTXprint lines up the texts of a diglot or polyglot: by chapters and verses,
or by a scoring method. See the **Diglot tab** chapter.

**Mirror (picture)** — To flip a picture from left to right, as in a mirror. See the **Pictures
tab** chapter.

**Mirror Pages** — A setting that makes left-hand and right-hand pages mirror each other, so that
items stay on the outer (or inner) edge. See the **Layout tab** and **Header+Footer tab** chapters.

**Monoglot** — A publication with only one text (not a diglot or polyglot).

## N

**Non-breaking space** — A space where PTXprint will never break the line. The two words on each
side always stay on the same line.

**Notelines** — Ruled lines printed in a wide margin, so readers can write their own notes. Used
for journaling Bibles. See the **Layout tab** chapter.

## O

**Odd and even pages** — Right-hand pages have odd numbers (1, 3, 5…). Left-hand pages have even
numbers (2, 4, 6…).

**OpenType** — The usual font technology. Most fonts are OpenType fonts. Compare **Graphite**.

**Ornament** — A small decorative pattern or graphic. PTXprint can use ornaments in borders and to
decorate pages. See the **Tabs+Borders tab** chapter.

**Orphan** — In typesetting, the first line of a paragraph left alone at the bottom of a column or
page. On the **Body** tab, **Prevent Orphan Words** is a different idea: it stops one short word
being left alone on the last line of a paragraph. Compare **widow**.

## P

**Padding** — Empty space inside a box or border, between the edge and the text. Set it in the
**Border Settings** dialog (see the **Tabs+Borders tab** chapter).

**Page filling** — Making the text reach the bottom margin on every page, so that no page ends too
early. You do it by adjusting paragraphs in the PDF Preview window, by hand or with **Auto Page
Fill**.

**Paragraph style (paragraph marker)** — A style for a whole paragraph, for example `\p`
(normal paragraph), `\q1` (poetry) or `\s1` (section heading). Compare **character style**.

**Parallel passage reference** — A reference printed under a section heading to show where the same
event is told in another book, for example "(Mark 1:1-8)". In USFM it is marked with `\r`.

**Paratext** — The program that translation teams use to write and check Scripture. PTXprint
prints the text of a Paratext project.

**PDF border (Legacy)** — A ready-made PDF graphic that PTXprint places behind headings or on every
page as a frame. Compare **dynamic border**.

**PDF Preview** — The PTXprint window that shows the PDF after you print. You can also use it to fix
the layout. See the **PDF Preview** chapter.

**PDF/A** — A type of PDF made for keeping documents for a very long time (archiving).

**PDF/X** — A type of PDF made for printing. **PDF/X-1a** is the older, strict type (CMYK, no
transparency). **PDF/X-4** is newer and allows RGB colours and transparency. See the **Finishing
tab** chapter.

**Penalty** — A number that tells the typesetter how much to avoid something, for example breaking
a word. A higher number means "avoid this more". 10000 means "never". Penalties are TeXpert
settings on the **Advanced** tab.

**Periph (peripheral section)** — A section of the front or back matter, for example the title page
or the preface. In the front matter each one starts with a `\periph` line.

**Peripheral book** — A book that is not Scripture text, for example front matter (FRT), back
matter (BAK), the glossary (GLO) or extra material (XXA, XXB…).

**PicList (picture list)** — The list of all the pictures in a configuration. Each line gives the
picture file, its anchor, caption, size and position. PTXprint makes it from the `\fig` entries in
the text, and then uses only the list. See the **Pictures tab** chapter.

**Placeholder** — An empty box printed where a picture would go. It keeps the layout but makes the
PDF very small.

**Polyglot** — A publication with three or more texts side by side. See the **Diglot tab** chapter.

**Primary text** — In a diglot or polyglot, the text of the configuration you started from (code
**L**). It controls the page size, margins, headers and footers. Compare **secondary text**.

**Project** — A Paratext project: the Scripture text that you want to print, with its settings.
Choose it on the **Basic** tab.

**pt (point)** — A small unit used for type. 1 pt is about 0.35 mm. 72 pt is about one inch
(25.4 mm). Font sizes and line spacing are given in points.

**Publication** — The book or booklet that you are making. On the **Publications** tab, a
publication is a named set of books that you can print together with others.

## Q

**Quick Run** — A check box in the bottom bar. PTXprint then runs the typesetting only once, which
is faster. Untick it for the final PDF, so that page references and the table of contents are
correct.

## R

**Ragged** — Text where one edge of the lines is not straight (for example ragged right). Compare
**justification**.

**Regular expression** — A way to describe patterns of text, used in changes files. This is an
advanced feature.

**Resolution (picture)** — How detailed a picture file is. Low-resolution files are small and good
for drafts. High-resolution files are large and needed for printing. Choose on the **Pictures**
tab.

**RGB** — The colours used by screens: Red, Green and Blue. Compare **CMYK**.

**River** — A line of white space that runs down through several lines of text, made by wide spaces
between words that happen to be one above the other. **Layout Analysis** marks rivers in yellow.

**Right-to-left (RTL)** — Scripts that are written from right to left, for example Arabic and
Hebrew. Set the direction on the **Fonts+Script** tab.

**Rule** — A thin straight line, for example under the header, between columns, or above the
notes.

## S

**Script** — A writing system, for example Latin, Arabic, Devanagari, Myanmar or Han (Chinese). Set
the **Text Script** on the **Fonts+Script** tab.

**Secondary text** — In a diglot or polyglot, each text other than the primary text (codes **R**,
**A**, **B**…). Each secondary text has its own configuration for its fonts and other text
settings.

**Section heading** — A heading inside a book that names the next part of the text. In USFM it is
marked with `\s1`, `\s2` and so on.

**Send/Receive** — The Paratext command that shares changes with the rest of the team. PTXprint
configurations are shared this way. The PDFs are not.

**Sidebar** — A box of extra text, for example a study note about a place or a person, separate
from the Scripture text. In USFM it starts with `\esb` and ends with `\esbe`. See the **Styles
tab** chapter.

**Signature** — A group of sheets that are folded together and sewn or glued into the book as one
unit. See the **Finishing tab** chapter.

**Span (Span Width)** — The full width of the text area, across both columns. Used for pictures and
boxes.

**SpeedSlice** — A tool in the PDF Preview window that typesets only a few chapters of a long book,
so that each print is fast while you fix pages. Always turn it off before the final PDF. See the
**PDF Preview** chapter.

**Spot colour** — One extra, ready-mixed ink used together with black, for example red for
headings. See the **Finishing tab** chapter.

**Spread** — Two facing pages of an open book: a left-hand page and the right-hand page beside it.

**Strong's numbers** — Numbers that identify each Hebrew and Greek word of the Bible. PTXprint can
use them in cross-references and to make an index. See the **Notes+Refs tab** chapter.

**Style** — The formatting rules for one marker: its font, size, colour, indents, alignment and
spacing. Change styles on the **Styles** tab.

**Stylesheet** — A list of styles for all the markers. PTXprint combines the Paratext stylesheet
with its own additions and your changes. See the **Styles tab** chapter.

## T

**Table of contents** — A list of the books with their page numbers, usually in the front matter.
Turn it on with **Table of Contents** on the **Peripherals** tab.

**TeXpert settings** — About 125 fine settings for the typesetting engine, on the **Advanced** tab,
**Other** sub-tab. They are for experienced users. Labels turn bold when a value is changed.

**Text area** — The part of the page where the main text goes. The margins are outside it.

**Thumb tab** — A coloured block printed at the outer edge of the page, with a short book name in
it. When the book is closed, the reader can see the tabs and open the book at the right Bible
book. See the **Tabs+Borders tab** chapter.

**Tofu** — The empty box (☐) that is printed when the font has no shape for a character. Use a
fallback font or another font to fix it.

**Transcelerator** — A Paratext plugin for making comprehension-checking questions. PTXprint can
print the questions. See the **Notes+Refs tab** chapter.

**Trim size** — The size of the finished book page after the printer cuts it. In PTXprint this is
the **Page Size** on the **Layout** tab.

**Typeface (face)** — One style of a font: Regular, Bold, Italic or Bold Italic.

## U

**Underfilled page** — A page or column where the text stops before the bottom margin. PTXprint
lists these in the PDF Preview window, so you can fix them.

**Unicode** — The international standard that gives a number to every character in every script.
A character can be written as `U+` and a hexadecimal number, for example U+06DD.

**USFM** — Unified Standard Format Markers. The way Paratext stores Scripture text, with markers
such as `\p`, `\v` and `\f` that say what each piece of text is.

**USX** — An XML format for Scripture text, used for example in DBL text bundles.

## V

**Variable** — A place-holder in the front matter, written as `\zvar|name\*`. When you print,
PTXprint replaces it with a value from the variables table on the **Peripherals** tab, for example
the title of the book.

**Variable Line Spacing** — A layout choice where PTXprint may stretch the space between lines a
little so that every column is filled to the bottom. Compare **Align Text to Baseline**.

**View level** — How many settings PTXprint shows: **Mini**, **Basic**, **Default** or **Full**.
Hidden settings still work. Change it with **☰** › **View Level** (see the chapter **The main
window, menu and view levels**).

## W

**Watermark** — A light text or picture printed on every page, for example the word "DRAFT". Add it
on the **Finishing** tab.

**Widow** — In typesetting, the last line of a paragraph left alone at the top of a column or page.
On the **Body** tab, **Prevent Verse Widow Words** is a different idea: it stops a verse number and
a short word being left alone at the end of a line. Compare **orphan**.

## X

**XeTeX** — The typesetting program that PTXprint uses behind the scenes to place the text on the
pages. You never need to use it yourself. Its report of the last print run is on the **View+Edit**
tab (**XeTeX Log**).

## Z

**z-codes** — Extra codes that start with `\z` and that PTXprint understands in addition to normal
USFM markers, for example `\zcopyright`, `\zvar|...\*` or `\ztoc|main\*`. They are used mostly in
the front matter. See the **View+Edit tab** chapter.

**ZIP file** — A file that holds other files packed together. PTXprint uses ZIP files for archives,
image sets and printer orders.
